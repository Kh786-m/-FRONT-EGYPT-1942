# بناء APK باستخدام GitHub Actions من الهاتف

هذه حزمة مشروع Android جاهزة لإرسالها إلى GitHub Actions. لم يُبنَ APK بعد.

## الخطوات
1. افتح GitHub على الهاتف وسجّل الدخول.
2. أنشئ مستودعاً خاصاً جديداً، ثم ارفع **محتويات** هذا المجلد مع الحفاظ على بنية المجلدات، وخاصة `.github/workflows/build-apk.yml`.
3. افتح تبويب Actions في المستودع، ثم اختر `Build WAR FRONT Android APK` واضغط `Run workflow` (أو انتظر التشغيل التلقائي عند رفع الملفات إلى main).
4. بعد نجاح البناء، افتح التشغيل ثم قسم Artifacts، ونزّل `WAR_FRONT_EGYPT_1942_debug_APK`.
5. فك ضغط Artifact على الهاتف، ثم ثبّت `app-debug.apk` إن سمح Android بالتثبيت من هذا المصدر.

**ملاحظة:** واجهة GitHub على الجوال قد لا تسمح برفع المجلدات دفعة واحدة. يمكن استخدام GitHub Codespaces من المتصفح ورفع ZIP ثم فك ضغطه في مساحة العمل قبل commit/push. هذا يتطلب حساب GitHub وقد يخضع لحدود استخدام. لا ترفع ملف ZIP نفسه فقط إلى المستودع؛ يجب أن تكون الملفات مفكوكة في جذر المستودع.

التطبيق غلاف WebView للنسخة التجريبية غير المتصلة بالإنترنت، وليس لعبة Unreal أو لعبة PUBG. البناء السحابي قد يفشل ويتطلب معالجة أخطاء Gradle أو Android SDK. استخدم نسخة debug للاختبار فقط، لا للنشر في المتجر.
