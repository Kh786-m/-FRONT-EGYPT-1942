# WAR FRONT: EGYPT 1942 — Godot 4 3D Prototype

نموذج أولي ثلاثي الأبعاد قابل للتطوير للهواتف، وليس لعبة PUBG كاملة أو منتجًا نهائيًا.

## الموجود فعليًا
- ساحة قتال صحراوية ثلاثية الأبعاد تُبنى إجرائيًا مع مبانٍ وجدران.
- إضاءة شمسية وظلال وكاميرا FPS وسلاح ظاهر على الشاشة.
- تحكم باللمس: عصا حركة، تحريك الكاميرا بالسحب، FIRE وJUMP وRUN.
- تحكم حاسوب: WASD، الفأرة، Space، Shift.
- 12 هدفًا يمكن إصابتها بثلاث طلقات لكل هدف، وعدّاد نتائج.
- لا يحتاج إلى أصول خارجية أو اتصال بالإنترنت.

## التشغيل
1. افتح المجلد في Godot 4.3 أو أحدث (Compatibility renderer).
2. اضغط Run Project لتجربة المشهد.
3. لتصدير Android APK: ثبّت قوالب التصدير الخاصة بإصدار Godot، واضبط Android SDK وJava/keystore من إعدادات Godot، ثم أنشئ Android export preset.
4. اختبر أداء الهاتف وخفّض الظلال أو عدد المباني إذا لزم الأمر.

## الحدود
هذا نموذج هندسي أولي: المجسمات منخفضة التفاصيل ولا توجد شخصيات متحركة أو صوت أو شبكة أو نظام مباريات. الجودة السينمائية الواقعية تتطلب أصول 3D ومواد PBR ورسوم متحركة وتحسينات أداء واختبارات لاحقة. لم يُنتج APK ضمن هذه الحزمة.
