# شخصية البطل — خالد كارم عبداللا

- تم إدراج الصورة التي قدمها المستخدم كصورة شخصية داخل شاشة البداية في Godot.
- اسم البطل ظاهر بالعربية والإنجليزية.
- أضيفت شاشة بدء مهمة مستقلة وزر دخول اللعب.
- تم إيقاف حركة اللاعب والقتال قبل بدء المهمة.
- الصورة ليست نموذج وجه ثلاثي الأبعاد ولا يوجد بعد نموذج جسم متحرك يشبه الشخص.
- هذا مشروع تجريبي، يحتاج إلى اختبار في Godot 4.3+ وإلى بناء APK فعلي.
- للحفاظ على الخصوصية: يتضمن ZIP صورة المستخدم، فلا ترفع المشروع إلى مستودع عام إذا لم تكن تريد نشر صورتك.
